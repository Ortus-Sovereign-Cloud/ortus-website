# Ortus

Ortus is a workspace an organisation runs itself: mail, calendar and contacts, files, documents, chat, calls, tasks, approvals and records, with sign-in, policy and audit for the whole organisation. It is one program; it runs on one machine or on Kubernetes, and every part of it is open source under MIT or Apache-2.0.

- [Install on one machine](install.html): Linux with systemd, SQLite and a directory of files.
- [Install on Kubernetes](kubernetes.html): the chart, PostgreSQL and S3.
- [Backups and restore](backups.html): nightly backups, hourly restore points, bringing one folder back, the restore test.
- [Upgrades](upgrades.html): what happens to the data, and going back.
- [Calls](calls.html): the media server, and calls on networks that allow only web ports.
- [Integrations](integrations.html): webhooks, the directory, sign-in with outside providers.
- [Phones](phones.html): the iOS and Android apps, and the phone as a key.
- [API reference](api/index.html): every operation of the core and its apps.
